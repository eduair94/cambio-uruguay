# Fotos con IA — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Abaratar y ampliar la visión de autos y juntar en sombra los hechos visuales de alquileres y ventas, con etiquetado humano y veredicto por atributo, más el evento GA4 de filtros.

**Architecture:** Un helper compartido de fotos en JS puro (`classes/vision/photos.ts`) baja, descarta, achica y huellea; `classes/anthropic.ts` gana caché del `system` y devuelve el costo; autos usa ambos; un job nuevo (`sync_photo_facts.ts` + `classes/photofacts/`) escribe sólo en colecciones privadas; scripts de etiquetado y veredicto leen esas colecciones; el app emite `directory_filter`.

**Tech Stack:** TypeScript 6 (CJS), mongoose 9 / driver nativo, `@anthropic-ai/sdk` 1.6.0, `jpeg-js` 0.4.4 (nuevo, JS puro), vitest, Nuxt 4 (app).

**Spec:** `docs/superpowers/specs/2026-11-23-fotos-ia-design.md`

## Global Constraints

- VPS CentOS 7, glibc 2.17: ninguna dependencia nativa nueva; `jpeg-js` es la única dependencia nueva.
- Toda llamada a Claude por `classes/anthropic.ts`; ningún otro archivo importa `@anthropic-ai/sdk`.
- Nada de este trabajo escribe en `rentallistings`, `propertysalecatalog` ni en una API pública.
- El esquema nunca pide matrículas, caras, teléfonos ni texto de las fotos; el prompt nunca lleva la descripción del aviso.
- Atributos de comodidades: `si | no_se`; mobiliario: `si | no | no_se`.
- Fotos: lado mayor 1.024 px, JPEG calidad 80; descartar < 400 px de lado mayor o < 4.096 bytes.
- Odómetro retira oportunidad sólo si `foto > 1,25 × declarado` y `foto − declarado ≥ 20.000`.
- Presupuesto del job: `PHOTO_FACTS_MAX=40`, `PHOTO_FACTS_MINUTES=6`, `PHOTO_FACTS_MONTHLY_USD=8`, `PHOTO_FACTS_ENABLED`.
- Cron `12 * * * *`, `import "./sentry_job"` primera línea, app en `OTHER_APPS`.
- Vara de publicación: precisión ≥ 0,95 con n ≥ 100 y positivos ≥ 30.
- GA4: `directory_filter` con `{ directory, filter, action }`, nunca el valor.
- Repo público: sin cifras de ingreso, sin consultas de búsqueda.

## Review Focus

- Foto que el CDN sirve como WebP detrás de `.jpg`, o AVIF: no se decodifica → se manda tal cual si Claude la acepta, se descarta si no (`sniffImageMime` null). Test en Task 1.
- Galería con la misma foto repetida bajo dos URLs (portada en otro tamaño): el SHA-1 del contenido la descarta; la variante de tamaño distinto no, pero su dHash la marca (distancia ≤ 4) y también se descarta. Test en Task 1.
- Aviso de autos sin km declarado (`km: null`) con odómetro legible: nunca retira. Test en Task 3.
- Respuesta del modelo con índices de foto fuera de rango o portada apuntando a un plano: se normaliza (portada `null`, índices filtrados). Test en Task 4.
- Mes nuevo: el tope mensual suma sólo lo leído desde el día 1 UTC del mes. Test en Task 5.
